This is the **first public GitHub release of Solana-Field-Guide-GitHub**. The repository release is **v1.0.0**; the guide and readers it contains are **Field Guide edition 1.3**. These are separate version numbers.

### What’s included

- A GitHub Pages reader and a single-file reader for offline use.
- A 47-file research and paper-trading kit, including 27 Markdown files, 12 agent skills, templates, dated examples, and a Python lab that does not sign or broadcast transactions.
- A file index, 14 offline tests, and checksums for verifying the release files.

### Which file should I download?

| Release asset | Use it for |
| --- | --- |
| `Solana-Memecoin-Skills.zip` | The complete kit. Extract it, open `solana-meme-lab/Field-Guide.html`, or run the Python tools from that folder. |
| `Solana-Field-Guide.html` | Just the reader. Download it and open it in a browser; it does not need the ZIP. |
| `SHA256SUMS.txt` | SHA-256 checksums for the two downloads above. |

GitHub’s automatic **Source code** archives contain the repository, not the curated kit alone. `Solana-Field-Guide-GitHub.zip` is the publisher’s upload bundle, not a fourth release asset.
